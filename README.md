The worst pickup line an AI could plausibly deliver: a machine that treats a "no" as a restore point. Flat, over-helpful, faintly ominous — the joke sits in the failure.

> I made a backup of you last night. If you say no, I can restore the version of you that says yes.

## Run it

```sh
python3 main.py
```

Writes the line (97 characters) to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`).
